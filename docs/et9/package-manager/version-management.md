## 主要用于 ET包开发者使用

检查当前所有包之间的版本关系

因为各个包之间依赖相对复杂且多 手动不好调整 因此才有了这个版本管理功能

常规用户可无视此功能  如果要使用请慎重 且懂 且会...

:::

### 如:

![](/images/et9/img/UIt5bw5wbo7Sp6x7Zx5ckFiznWb.png)

当前包: yiuiframework

当前版本: 0.0.11 也是最新版本

### 依赖:

"cn.etetet.core": "0.0.14",

"cn.etetet.yiui": "0.0.10"

这里可以看到没有同步按钮 说明当前安装的这2个包版本一致  如果不一致会出现同步按钮

![](/images/et9/img/VkEQbZmcxoWmUpxLn05ckYUsnKc.png)

比如这个: gm包 依赖yiuiframework的0.0.10版本 但是当前安装的是0.0.11版本 说明不一致

这里可以点击同步 则当前gm包的版本号就对上了

### 同步生成

是否需要同步根据你自己的需求想法即可点击同步后并不会马上执行修改文件

点击同步按钮后 将会修改所有信息 这个时候就可以根据需求上传重新打包了

### 强制本地同步

本地手动修改版本号时  不会触发编辑器的编译 所以无法知道改变了  要么重启unity

或者你点一下这个强制本地同步 可以重新同步到你手动修改的版本号  建议不要手动手改

### ~~强制网络同步~~

~~当前有可能你本地改了版本  但是忘记网络版本是多少时 可以使用 则会强制修改版本号~~

### 强制依赖同步

功能一:

当你 A包 你手动升级了个版本

按照逻辑  假设B包有关联A 那么A升级了 所以B也必须升级 所以这个按钮也会同时升级B包 +1

如果你已经手动 B包改过  则就不会+1了 会使用你手动改过的 没改就会+1

功能二:

你可以理解为帮你把界面上所有同步按钮按一遍

备注: 这个强制依赖按钮点了过后只是修改了当前缓存数据 还是需要你点一下同步生成按钮的

::: tip 🚅
各种同步中 都有可能一直在读条中
只能是因为网络问题  如果不想等了 就重启Unity
:::
