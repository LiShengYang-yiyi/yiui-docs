# ETPackageManager 包管理

## PackageManager

安装方式与ET9其他包安装方式相同

包名:cn.etetet.packagemanager

地址:https://github.com/ET-Packages/cn.etetet.packagemanager

## 依赖 Odin

依赖odin插件作为可视化  Unity商店付费插件请自行购买

版本保持最新即可

[更新检查](/et9/package-manager/update-check) (如果没有Odin 会有这个功能 其他功能需要Odin)

![必须装了Odin插件才能看到这个选项](/images/et9/img/JxgTbYJl3oXz8PxywbpcT5Uqnuh.png)

没有装Odin插件的 看到的就是这个更新检查

## 未命名

### 更新检查

::: tip 🍞
非Odin 时的功能
如果安装Odin插件 就会得到更加丰富的管理功能界面
:::

相对简陋的功能 会自动检查当前所有ET插件最新版本

比对当前版本是否有包有更新

然后展示在界面中

自己根据提示信息更新

只是告诉你有更新 具体什么更新 请参考官方文档
