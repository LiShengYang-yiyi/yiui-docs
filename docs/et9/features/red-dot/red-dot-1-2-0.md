# 红点 1.2.0 修改日志

## 可运行时修改红点绑定Key

给动态红点用的

如 3个页签是动态生成的 每个页签绑定的Key在预制上是未知的

以前做法是自己写代码监听, 现在可以用通用预制然后修改里面的key即可

## 可手动选择Key

![](/images/et9/img/KipebGTuuoPXSRx304jcM0Oonvb.png)

之前只能 选上面的下拉菜单

如果你的红点非常多了过后发现这个下拉菜单很长 可能不好找

可以使用下面的手动选择  输入对应的Key 即可
