YIUI并不推荐刚入门的新人学习 特别是ET框架的YIUI

如果你确定要学习 请付出比别人更多的努力

### **问答**

比如 你遇到一个热更问题 理应找热更插件

::: tip ❤️ 谦逊和尊重
:::

提问和回答问题的过程中，保持谦逊和尊重是非常重要的，这有助于建立一个积极和建设性的交流环境

1. **提问时的谦逊**：

   - **尊重知识**：认识到自己可能不知道所有答案，并且愿意向他人学习。
   - **清晰表达**：尽量清楚地表达自己的问题，以便于他人理解并提供帮助。
   - **开放态度**：对不同的意见和观点持开放态度，愿意接受和考虑。
2. **提问时的良好品德**：

   - **感激之情**：对那些愿意花时间帮助解答问题的人表示感谢。
   - **诚实**：如果问题已经得到解答或自己找到了答案，应该及时告知，避免浪费他人的时间。
   - **自我反思**：在提问前先尝试自己解决问题，这不仅是对自己能力的锻炼，也是对他人时间的尊重。
3. **回答问题时的谦逊**：

   - **知识共享**：愿意分享自己的知识和经验，帮助他人成长。
   - **耐心**：即使问题看似简单或重复，也应保持耐心，因为每个人学习的速度和方式都不同。
   - **谦卑**：认识到没有人是无所不知的，即使在某个领域有专业知识，也应该保持谦卑，因为总有更多可以学习的地方。
4. **回答问题时的良好品德**：

   - **尊重提问者**：即使问题可能显得基础或简单，也应该尊重提问者，避免表现出任何形式的轻视或不耐烦。
   - **准确性**：提供准确和可靠的信息，避免误导。
   - **鼓励探索**：鼓励提问者继续探索和学习，而不仅仅是提供答案。
5. **共同的品德**：

   - **沟通技巧**：无论是提问还是回答，都应该使用清晰、礼貌的语言。
   - **持续学习**：认识到交流是一个双向学习的过程，每个人都可以从中获得新的见解和知识。
   - **社区精神**：培养一种社区感，每个人都是为了共同的目标——知识的增长和分享——而努力。

## 补充

到底什么才叫做 不要遇到问题就问

到底什么问题可以问 到底怎么个定义

就是你遇到问题时 有没有自己尝试过去解决

参考 上面的 遇到问题

比如

1. 查了文档
2. 百度
3. AI
4. 断点
5. 日志
6. ......

重点就是你有自己尝试过解决  只要你尝试过 但还是无法解决的问题都可以问

如果你要犟 这个尝试过的度是什么  那就要看你自己把握了

不要遇到问题就问 就是指 **不要还没自己尝试过解决问题就开始问**
