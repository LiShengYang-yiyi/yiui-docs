# 配置表可视化工具

由于目前所有包分散在各个包里面

对于程序来说没有什么压力也简单

分包策略是必须的 有利于程序代码的维护 等等好处

但是对于策划 美术 只使用配置来说可能理解上会差很多

因此提供了一个可视化工具 可以在工具中预览所有配置

不必去每个包中查找等等

且增加了 包的 别名 备注 / 配置的 别名 备注

此功能也可提升配置表的理解 可读性 提升效率

::: tip ⚽ 依赖YIUI / Odin
:::

## 所有配置

除了可以在单个包中浏览当前包的所有配置 也可以直接查看全部配置

查看全部配置时 就不是按包排序了 使用的是首字母排序

查看全部配置时 会忽略Base文件夹 如果需要定义还是建议到对应包中修改

![](/images/et9/img/DkBZbc68boYsk0xTyZnc3RCmnvb.png)

## 搜索

不管是在所有配置下 还是指定的包中 都有搜索功能

可以按名称/别名搜索  也可以按描述搜索

针对大型项目非常多表时自定义的设定可以增加搜索效率
