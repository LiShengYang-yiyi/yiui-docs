# 界面与配套能力

YIUI 体系下与界面配套的能力。每一项都可以单独选用，删除不影响框架运行。

| 能力 | 解决什么问题 |
|---|---|
| [红点](./red-dot/) | 业务状态如何聚合成「哪里该亮」：key 编码规则、红点树层级、职责边界、UI 绑定、动态挂载、排查、新增流程 |
| [循环列表](./superscroll/) | 长列表如何只创建可见项并复用：三套控件的选型、Item 池、刷新、点击与选中 |
| [提示弹窗](./tips/) | 飘字与确认框如何共用一个通道：池化复用、引用计数、排队、等待玩家选择 |
| [对象池](./gameobjectpool/) | 同一个资源被反复创建销毁时如何复用：按资源名分桶、三种自动回收、并发上限 |
| [调用系统](./invoke/) | 跨层调用如何不写死实现：参数结构体 + 标识、两条通道、监听切片 |
| [条件系统](./condition/) | 「满足什么条件才开放」如何统一表达：配置表结构、多条件组合规则、监听与触发 |
| [多语言](./localization/) | 文本与资源如何随语言切换：三条取词入口、缺 Key 策略、切语言全场景刷新、源表到强类型 Key 的生成链 |
| [声音](./audio/) | 音效与背景音乐如何统一播放：播放句柄、分组音量、BGM 优先级、clip 引用计数 |
| [UGUI 特效](./effect/) | 粒子如何和界面排在同一个层级：烘焙成网格、Mask 裁剪、材质级特效、置灰绑定 |
| [UI 挂点](./mountpoint/) | 预制体里的关键节点如何稳定定位：收集器与标记、字符串键、取挂点、换模重绑 |
| [GM 面板](./gm/) | 调试命令如何不改面板代码就接进来：特性 + 接口、参数自动成控件、执行与历史 |
| [UI 内 3D](./3ddisplay/) | 界面里怎么显示真 3D 模型：独立层 + 专属相机 + RenderTexture、多实例隔离、拖拽与射线点击 |
| [伤害提示](./damagetips/) | 战斗飘字怎么落到世界与界面两个空间：六个入口、样式靠换预制体、跟随与池化回收 |
| [资源接入 YooAssets](./yooassets/) | 界面与图集资源从哪加载：四个加载委托、引用计数、图集生成、资源收集规则 |
| [数值系统](./numeric/) | 属性值怎么统一管理：成长项与公式、万分位定点数、变化监听、上下限与影响链 |
| [Luban 配置底座](./luban/) | 表怎么变成代码与数据：表定义 DSL、导出流程、运行时加载、新增一张表 |
