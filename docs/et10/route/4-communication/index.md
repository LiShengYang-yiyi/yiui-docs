# 阶段 4 · 会跟服务器说话

> **一句话**：这一阶段把「一条消息从客户端发出、到服务端处理、再回到客户端」的全过程讲透——协议怎么定义、Handler 怎么挂、内网消息怎么转发、客户端怎么找到服务器。

前面三个阶段都是在**单个进程内**打转。从这里开始进入真正让 ET 复杂起来的部分：**网络**。

理解顺序是**沿着一条消息走**：

```
定义协议 → 写 Handler → 服务端之间转发 → 找到对的服务器
  (4.1)      (4.2)         (4.3)            (4.4)
```

不按「包的依赖顺序」讲（那会先讲 netinner 再讲 proto，读起来毫无上下文），而是按消息的实际流向讲。
