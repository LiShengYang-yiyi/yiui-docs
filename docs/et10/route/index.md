# ET10 学习路线

> **一句话**：这是 ET10 的主线。8 个阶段按「理解顺序」排列——先跑起来，再理解框架，最后进 YIUI。

## 为什么这样排

包与包的依赖顺序（先 `core` → 再 `proto` → 再 `loader`）是**构建顺序**，不是**理解顺序**。照那个顺序学，前三天都在读基础设施，看不到任何能跑的东西。

这条路线排的是理解顺序：

```
跑起来 → 建立世界观 → 懂代码分层 → 会跟服务器说话 → 懂服务端链路 → 进 YIUI
```

每一步都建立在上一步「已经看得见的东西」上，不提前引入还没用过的概念。

## 8 个阶段

| 阶段 | 名称 | 做完之后你能 | 小节 |
|---|---|---|---|
| **0** | [环境](./0-environment/) | 工程在你机器上编译通过 | 2 |
| 1 | [跑起来](./1-run-it/) | 启动服务器、登录、进入地图 | 3 |
| 2 | [ET 世界观](./2-et-model/) | 不再拿 Unity 的心智套 ET | 4 |
| 3 | [代码怎么组织](./3-code-layout/) | 新增任何代码都知道放哪一层 | 4 |
| 4 | [会跟服务器说话](./4-communication/) | 看懂一条消息从客户端到服务端再回来 | 4 |
| 5 | [服务端链路](./5-server-chain/) | 说清一个玩家从启动到站在地图上的完整路径 | 5 |
| 6 | [YIUI 客户端 UI](./6-yiui-ui/) | 写 Panel、做数据绑定、接常用组件 | 6 |
| 7 | [工具链与 AI](./7-toolchain/) | 用编译门禁 / MCP / 行为树，让 AI 参与开发 | 6 |

**8 个阶段、34 个小节**，按顺序走完就是一条完整的上手路径。

## 一条规矩

> **每个知识点只有一处正文页。**

路线上的每一节骨架固定：一句话 / 关键词 / 目标 / 前置 / 按序读什么 / 源码落点 / 真源 / 读完能回答 / 下一步。同一个知识点在站上只出现一次正文，其余地方只给链接。

这样改一处只需要改一处——不给未来的自己挖坑。
