# 阶段 3 · 代码怎么组织

> **一句话**：这一阶段解决「我要加一个功能，代码放哪」——分层、程序集、包依赖，三件事说清楚就不再需要问人。

工程跑通了、概念也换过来了，接下来是最高频的实际问题：**新增代码放哪。**

ET 对这件事的要求比一般工程严格，原因有三个：

1. **热更新**——逻辑必须单独成集，定义和逻辑混在一起就没法热更；
2. **多人协作**——每个人只熟悉自己的包，包边界不清就会互相踩；
3. **客户端与服务端同仓**——代码在一起，但运行时分离，混用不会被编译器拦住。

这三条决定了分层、程序集、包依赖都不是「风格偏好」，而是**分析器会强制校验的硬约束**。
