# 阶段 1 · 跑起来

> **一句话**：先把工程真正跑起来——服务端起来、客户端连上、能登录、能进地图。这一阶段结束前不读框架原理。

前三节里会有很多「照着做」的命令，暂时不需要理解背后的机制。**先把一个能运行的系统拿到手里**，后面所有概念都挂在它上面。

这样排的理由很简单：ET 的核心概念（实体、组件、纤程、消息）全都能在「登录进地图」这条链路上看到实例。先有现象，再讲原理。
