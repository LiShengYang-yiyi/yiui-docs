## 内容怎么组织

- **学习路线** —— 8 个阶段、34 个小节，从环境到工具链。侧边栏的顺序就是学习顺序。
- **界面与配套能力** —— 红点这类专题，每项写清「是什么 / 怎么配 / 边界在哪 / 出事怎么查」。
- **每个知识点只有一处正文页** —— 其余页面只给指向它的链接。

## 内容从哪来

正文以工程源码与实际实现为准，素材来自包内 `Desc/`、`AGENTS.md`、`Scripts/`、`Book/` 官方教程与 `cn.etetet.yiuimcp/Docs/`。

每页的「真源」一栏给的是**工程内路径**，方便直接打开原始文档与代码对照。
